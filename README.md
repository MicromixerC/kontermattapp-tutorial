# Konter a Matt — Tutorial

Interactive tutorial for the Luxembourgish card game Konter a Matt.
Live: https://micromixerc.github.io/kontermattapp-tutorial/

## Work on it
```bash
npm install        # once (or after dependencies change)
npm run dev        # local preview at http://localhost:5173/kontermattapp-tutorial/
```

## Publish
```bash
bash deploy.sh "what I changed"
```
Builds the site, publishes it to `main` (served by GitHub Pages) and backs up the source to the `source` branch.
